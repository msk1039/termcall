# Support

## Where to ask

- Use GitHub Issues for reproducible bugs and concrete feature requests.
- Search existing issues before opening a new one.
- Use [SECURITY.md](SECURITY.md) and GitHub private vulnerability reporting for
  security concerns; do not file security issues publicly.

## What support covers

This is an experimental volunteer-maintained project. Best-effort support is
available for the current `main` branch and newest prerelease. We cannot provide
guaranteed response times, managed hosting, call recovery, or support for
unsupported Windows builds.

## Helpful bug reports

Include the operating system, architecture, terminal emulator, TermCall commit
or release version, server URL scheme (`wss` or `ws`), and redacted logs. Never
include TURN secrets, credentials, or private call content.
